# Yandex Market Product Catalog

A simple responsive product catalog for Yandex Market with product categories, images, prices, and purchase links.

## Deploy with GitHub Pages

1. Create a new repository on GitHub.
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. Wait for GitHub Pages to publish the site.

## Notes

- Product images and product links currently use external Yandex Market URLs.
- Update product details in the `P` array inside `index.html`.
